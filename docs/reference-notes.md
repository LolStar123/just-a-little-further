## Implementation direction

1. Keep paper, graphite, large owl wings and the pen-to-signature identity. Use olive/ochre only to distinguish meaningful controls or data.
2. Show less introductory copy and more of the first useful project. Reserve scene height before it loads so mobile does not skip it during reflow.
3. Make meowl deformation a bounded articulated pose. Exaggerate anticipation, recovery and facial expression rather than stretching the torso.
4. Route all helper interaction through one toy-space system; coordinate scaling, release and cancellation must work identically across scenes.
5. Keep the line as one continuous route. Smooth join tangents, anchor measured chart coordinates, and allow springy tugging in spare space.
6. Retain calm visual staging. Hero and active scene take focus; distant sections suspend simulation/audio. Small handwritten annotation wobble does not affect paragraph text.
7. Distinct project sounds and original musical motifs crossfade, with one global volume control. Sound never substitutes for a visible state.
