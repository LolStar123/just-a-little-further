# Commute illustration selection

## Ten candidates
1. Ticket inspector compares two fares and stamps the cheaper ticket.
2. Ticket seesaw weighs the two costs.
3. Ticket machine takes workdays and prints the winner.
4. Coin race sheds fares along two routes.
5. Fare gates let the conductor pick the cheaper route.
6. Calendar-paper snowstorm.
7. Train eats expensive tickets.
8. Piggy-bank trampoline.
9. Umbrella catches falling coins.
10. Meowl juggles fare cards.

## Cull
Remove 6–10: decorative action obscures the fare decision.

## Finalists
| Idea | Benefit | Drawback |
| --- | --- | --- |
| Inspector | Compact, direct comparison, expressive character | Stamp must feel physical |
| Seesaw | Immediately legible comparison | Weight is an indirect metaphor for cost |
| Machine | Strong anticipation and payoff | Hides rejected alternative |
| Coin race | Energetic | Can imply travel speed |
| Fare gates | Fits transport theme | Requires more drawing space |

## Choice: ticket inspector
Keep six trains above. Below, show changing commute days and two priced paper tickets. The conductor walks toward the cheaper option and stamps it. Equal prices receive two stamps. It returns continuously to the centre between comparisons. Keep the shared canvas compact, the separate project links, and the existing toy interactions. Reuse the existing illustrative £6/day and £24/week values; the external calculator remains the source for real journey-specific fare calculations.
